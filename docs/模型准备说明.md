# 模型准备说明

把你的舞美模型做成一个可以三维浏览的网页文件：拖入模型，确认几项设置，下载一个 html。双击就能在电脑或手机浏览器打开，发微信、邮件给导演和甲方即可。

**你的模型不会上传到任何地方。** 所有处理都在你自己的电脑上、在浏览器里完成。

---

## 一、导出 FBX（必做）

在 3ds Max 里：**文件 → 导出 → 导出**，格式选 **FBX**，然后在导出设置里：

| 设置 | 选什么 | 不这样做会怎样 |
|---|---|---|
| 嵌入的媒体（Embed Media） | **勾选** | 屏幕画面、贴图不显示，只剩白模 |
| 动画（Animation） | 有升降、开合等机械时**勾选**，并勾选「烘焙动画」 | 机械动不了 |
| 单位 | 厘米或米 | 模型大小不对（人像蚂蚁或巨人） |
| 文件格式 | **二进制**（Binary），版本 FBX 2014 或更新 | ASCII 格式能显示，但无法自动识别灯具、无法精简 |

只支持 **FBX** 和 **GLB**。.max、.obj、.c4d、.skp 请先导出成 FBX。

## 二、材质和屏幕

- **屏幕画面**：用标准材质、物理材质或 VRay 灯光材质贴上画面，网页里会按屏幕自发光显示。
- **VRay / Corona 普通材质**：只保留颜色、反光等参数，贴图可能丢失。
- **贴图大小**：单张建议不超过 2048 像素，太大会让文件变大、手机打开慢。

## 三、灯具和桌椅

网页会找出模型里**重复出现的东西**（同一款灯、同一款椅子），再由你告诉它每种是什么。选了用途的会换成简单形状（灯口发光、光束、简单桌椅），文件小很多，生成的网页里还会有按组开关的灯光面板。

**建模时这样做，才找得准：**

1. **每台灯具是一个组**，同一款灯用同一个模型复制（从模型库下载的灯具通常已经是这样）。各自建模、没复制的，会被当成不同型号。
2. **按用途把灯分组**，比如「天排光束」「舞台两侧」「背后灯墙」。**最外层的组名就是网页上的灯光开关名**。

**生成时第 2 步，每种型号三选一：**

| 情况 | 结果 |
|---|---|
| **已认出**（自动填好） | 型号库里有这款灯，灯口位置、朝向、大小都准确，不用管 |
| **自己选用途**：光束灯 / 染色灯 / 频闪 / 灯条 / 椅子 / 凳子 / 桌子 | 灯口放在灯具中心、用默认大小；光束方向自动定（地上的灯朝上，天上的灯朝观众席），位置是近似的 |
| **不处理** | 按模型原样显示，但不发光、没有灯光开关，文件也大一些。不是灯具桌椅的、拿不准的选这个 |

**型号库还在扩充**，目前收录的型号还不多，所以多数型号要你自己选。**想让你常用的灯被自动认出，把一台灯的模型发给撒库拉**（联系方式在页面最下面），我们分析好灯口后加进库里，以后所有人都能自动认出。

带几百台灯具的模型可能有 1 GB 以上，这没关系，精简后一般只剩几十 MB。

## 四、升降台、升降屏、开合屏、旋转台（测试版）

生成的网页右侧会出现「机械」面板，每个会动的部件一个滑块。目前用 Blender 做的模型测试通过，3ds Max 导出的模型还在验证，遇到不动或动得不对请反馈。

### 推荐：在 3ds Max 里做动画

网页会读取动画，**自动认出哪些东西会动、往哪动、动多远**，生成的网页里会出现对应的控制滑块。

1. **一起动的东西编成一个组**：屏幕连同边框、桁架一起升降的，放进同一个组。开合屏的**左半、右半各编一组**。
2. **给组起个好懂的名字**，比如「主屏-左」「升降台A」。这个名字会显示在网页的控制面板上。
3. **打两个关键帧**：
   - **第 0 帧**：放在模型现在的位置（网页打开时的样子）
   - **最后一帧**：放在运动到头的位置（升到顶、完全打开、转到位）
   - 开合屏左右两半各自做动画，方向相反
4. **导出时**勾选「动画」和「烘焙动画」。

网页按运动方向自动判断类型：上下移动是**升降**，水平移动是**开合 / 平移**，绕竖轴转动是**旋转台**。

**做不了的**：布帘、软屏卷起这类**变形**动画；只支持整体的移动和转动。

### 以后：在网页上点选

没做动画的模型，以后可以在生成时点一下要动的物体来设置。这个功能还没做。

## 五、观众席方向

生成时网页会问观众席在舞台的哪一侧，按 3ds Max 的前、后、左、右视图选一个。选错了的话，「观众席」视角会看到舞台背面，回去换一侧重新生成。

## 六、模型太大怎么办

生成的网页大小，大约等于精简灯具桌椅之后的 FBX 大小。**建议控制在 50 MB 以内**，手机打开顺畅；超过 100 MB，有的手机可能打不开。

**先做最省事的：灯具和桌椅交给生成器。** 第 2 步给它们选好用途，几百台灯、几百把椅子的细节会被换成简单形状，这一步通常减得最多，不用在 3ds Max 里手动处理。

**还嫌大，在 3ds Max 里按顺序检查：**

1. **找出最重的东西**：按 **7** 打开视口统计，选中物体看面数；或者用「工具 → 多边形计数器」。往往是少数几样占了大半：观众席座椅、花艺绿植、雕塑装饰、从别处导入的 CAD 或扫描模型。
2. **删掉看不见的**：后台、舞台下面、被屏幕挡住的结构，隐藏或冻结了的旧方案，用不到的灯光、摄影机、辅助物体。导出时用「**导出选定对象**」，只导出要给别人看的部分。
3. **降低面数**：
   - 重的装饰物加 **ProOptimizer** 修改器，顶点降到 20%～50%，在视口里看不出差别就行。
   - **TurboSmooth / 网格平滑**的迭代次数调到 0 或 1 再导出。
   - 圆柱、管子、圆形桁架的**边数**减少（比如 32 改成 12）。
   - 样条线和文字的「**插值步数**」调小；可渲染样条线的边数调少。
4. **桁架换成简单版**：精细的桁架模型每节上百个面，几百节就很重。远看用简单的盒子或低面数桁架就够。
5. **贴图缩小**：单张不超过 2048 像素；照片类贴图用 JPG，不用 PNG；删掉凹凸、反射这类网页用不到的贴图。屏幕画面 1920 × 1080 就够清楚。
6. **导出时**：不勾「摄影机」「灯光」；没有机械动画就不勾「动画」。

改完重新导出，再拖进生成器，第 1 步会显示新的文件大小。

## 常见问题

有需求和建议？认识撒库拉的直接微信，不认识的发邮件：**stageviewer.app@outlook.com**

- **屏幕是白的**：导出时没勾「嵌入的媒体」，重新导出。
- **人物比例不对**：导出单位不对，改成厘米或米重新导出。
- **机械不动**：导出时没勾「动画」，或者关键帧打在了组里面的单个零件上而不是整个组上。
- **有灯具没认出来**：在确认那一步给它选用途；如果同一款灯的几台不是复制出来的（各自建模），可能被当成不同型号，分别选即可。
- **浏览器**：Chrome、Edge、Firefox 近两年的版本，Safari 16.4 以上（iPhone 需 iOS 16.4 以上）。
