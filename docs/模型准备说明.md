# 模型准备说明

把你的舞美模型做成一个可以三维浏览的网页文件：拖入模型，确认几项设置，下载一个 html。双击就能在电脑或手机浏览器打开，发微信、邮件给导演和甲方即可。

**你的模型不会上传到任何地方。** 所有处理都在你自己的电脑上、在浏览器里完成。

---

## 一、导出 FBX（必做）

在 3ds Max 里：**文件 → 导出 → 导出**，格式选 **FBX**，然后在导出设置里：

| 设置 | 选什么 | 不这样做会怎样 |
|---|---|---|
| 嵌入的媒体（Embed Media） | **勾选** | 屏幕画面、贴图不显示，只剩白模 |
| 动画（Animation） | 有升降、开合等机械时**勾选**，并勾选「烘焙动画」 | 机械动不了（可以在网页上补设置，见第四节） |
| 单位 | 厘米或米 | 模型大小不对（人像蚂蚁或巨人） |
| 文件格式 | **二进制**（Binary），版本 FBX 2014 或更新 | ASCII 格式能显示，但无法自动识别灯具、无法精简 |

只支持 **FBX** 和 **GLB**。.max、.obj、.c4d、.skp 请先导出成 FBX。

## 二、材质和屏幕

- **屏幕画面**：用标准材质、物理材质或 VRay 灯光材质贴上画面，网页里会按屏幕自发光显示。
- **VRay / Corona 普通材质**：只保留颜色、反光等参数，贴图可能丢失。
- **贴图大小**：单张建议不超过 2048 像素，太大会让文件变大、手机打开慢。

## 三、灯具和桌椅

网页会自动找出模型里重复出现的灯具和桌椅，把它们换成简单的形状（灯口发光、光束、简单桌椅），大幅缩小文件。为了让它认得准：

1. **每台灯具是一个组**，同一款灯用同一个模型复制（从模型库下载的灯具通常已经是这样）。
2. **按用途把灯分组**，比如「天排光束」「舞台两侧」「背后灯墙」。**最外层的组名就是网页上的灯光开关名**。
3. 生成时网页会列出识别到的每种灯具和桌椅，已认识的型号会自动填好，不认识的请你从下拉框里选「光束灯 / 染色灯 / 频闪 / 灯条 / 椅子 / 凳子 / 桌子」，或者选「不是灯具」。

带几百台灯具的模型可能有 1 GB 以上，这没关系，精简后一般只剩几十 MB。

## 四、升降台、升降屏、开合屏、旋转台

### 推荐：在 3ds Max 里做动画

网页会读取动画，**自动认出哪些东西会动、往哪动、动多远**，生成的网页里会出现对应的控制滑块。

1. **一起动的东西编成一个组**：屏幕连同边框、桁架一起升降的，放进同一个组。开合屏的**左半、右半各编一组**。
2. **给组起个好懂的名字**，比如「主屏-左」「升降台A」。这个名字会显示在网页的控制面板上。
3. **打两个关键帧**：
   - **第 0 帧**：放在模型现在的位置（网页打开时的样子）
   - **最后一帧**：放在运动到头的位置（升到顶、完全打开、转到位）
   - 开合屏左右两半各自做动画，方向相反
4. **导出时**勾选「动画」和「烘焙动画」。

网页按运动方向自动判断类型：上下移动是**升降**，水平移动是**开合 / 平移**，绕竖轴转动是**旋转台**。

**做不了的**：布帘、软屏卷起这类**变形**动画；只支持整体的移动和转动。

### 没做动画也可以：在网页上点选

生成时在三维预览里**点一下要动的物体**，选「升降 / 开合 / 旋转」，再拖到运动到头的位置。适合来不及做动画的模型，或者临时补几个。

## 五、观众席方向

生成时网页会问观众席在舞台的哪一侧，在预览里点选即可。选错了的话，「观众席」视角会看到舞台背面，回去换一侧重新生成。

## 常见问题

- **屏幕是白的**：导出时没勾「嵌入的媒体」，重新导出。
- **人物比例不对**：导出单位不对，改成厘米或米重新导出。
- **机械不动**：导出时没勾「动画」，或者关键帧打在了组里面的单个零件上而不是整个组上。也可以在网页上点选补设置。
- **有灯具没认出来**：在确认那一步给它选用途；如果同一款灯的几台不是复制出来的（各自建模），可能被当成不同型号，分别选即可。
- **浏览器**：Chrome、Edge、Firefox 近两年的版本，Safari 16.4 以上（iPhone 需 iOS 16.4 以上）。
