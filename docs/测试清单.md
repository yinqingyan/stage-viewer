# 舞美生成器测试清单

请用你自己的舞美模型，在 https://yinqingyan.github.io/stage-viewer/ 上把下面每一项试一遍。每项在「结果」里勾「通过」或「有问题」，有问题的写在「备注」里。

## 怎么测

1. 用电脑上的 Chrome、Edge 或 Safari 打开 https://yinqingyan.github.io/stage-viewer/ ，先点「模型准备说明」看一遍导出要求。
2. 准备 2～3 个你做过的模型，最好包括：一个带灯具的、一个带桌椅的、一个大的（几百 MB 以上）。3ds Max 导出 FBX 时勾选「嵌入的媒体」，格式选「二进制」。
3. 按下面的表逐项试，勾选结果，问题写在备注里。

模型只在你自己的电脑上处理，不会上传，可以放心用正式项目的模型。

## 还没做的功能（先不用测）

- **机械的网页点选**：没做动画的模型，还不能在网页上点选设置升降、开合。
- **新型号灯具的精确灯口**：生成器没认出、由你自己选用途的灯具，灯口放在灯具中心、用默认大小，位置可能有偏差。
- **秀导走位版**：还没放进生成器。
