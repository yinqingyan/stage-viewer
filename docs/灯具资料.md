# 舞台灯具参考资料

用途：给 3ds Max 舞台模型转 3D 网页工具提供两样东西：一是四种渲染类型（beam / wash / strobe / ledBar）的默认参数，二是可选的真实灯具型号。机器可读版本见同目录 `fixtures-reference.json`，字段与本表一致，另含 `keywords[]`。

整理时间：2026-11。所有数字均来自下表链接页面（已实际打开核对）。没有公开数据的格子留空，不做猜测。

## 1. 数据说明

- **sourceType**：`manufacturer` 是厂商官网产品页或官网 PDF；`datasheet` 是厂商官方规格书/说明书，但文件托管在经销商或租赁商网站（martin.com、elationlighting.com 等拒绝自动访问时采用）。本表没有任何一条只靠经销商自己写的参数。
- **角度**：厂商有的公布光束角（beam，50% 光强），有的公布场角（field，10%），也有“变焦范围”。混合灯的范围是各模式的最小值到最大值，备注里分模式列出。固定角度的灯 min=max。
- **前镜**：指前透镜/出光口直径（mm）。条形灯和面板写外形或发光面 W×H，备注注明是哪一种。大部分 LED 染色灯、频闪、灯条厂商**不公布**前镜或发光面尺寸。
- **renderType 映射规则**：
  - beam：光束灯、光束图案混合灯（三合一/BSW 按光束模式）、追光灯
  - wash：LED 染色、帕灯，以及图案/切割灯。切割灯在舞台上多以 15–30° 打主光或图案，比 3° 光束粗得多，所以暂归 wash，具体角度和镜头用型号覆盖。
  - strobe：频闪、观众灯/四眼灯
  - ledBar：灯条、洗墙灯

| 俗称 | 含义 | 建议 renderType |
|---|---|---|
| 电脑灯 / 摇头灯 | 泛指 DMX 控制的摇头灯，不代表具体光型 | 看其他关键词；默认 beam |
| 光束灯 / 光束 / 7R / 230光束 / 2R / 17R / 280 / 295 / 380 / 470 | 极窄硬光柱（约 2–4°）。数字是灯泡瓦数或型号，如 7R≈230W | beam |
| 三合一 / BSW / 四合一 / BSWF / 混合灯 | 光束+图案+染色（+切割）一体机 | beam |
| 图案灯 / Spot | 打 gobo 图案 | wash（中等角度）或 beam |
| 切割灯 / Profile / Framing | 带切割刀片的图案灯 | wash（角度 15–30°） |
| 成像灯 / 椭球灯 / Leko / Source Four | 固定式成像灯，多用于面光、耳光 | wash |
| 面光灯 / 耳光 / 侧光 / 逆光 / 顶光 | 按安装位置命名，不是灯种 | 看灯种关键词 |
| 染色灯 / Wash / LED染色 / 19颗 / 19x15 / 19x40 / 蜂眼 / 蜂巢 / B-EYE | 柔边大角度染色；蜂眼是多颗 LED 带独立透镜 | wash |
| 帕灯 / PAR / PAR64 / 帕 | 帕灯（传统或 LED） | wash |
| 柔光灯 / 聚光灯 / 回光灯 / Fresnel | 传统剧场/电视灯 | wash |
| 天幕灯 / 天排灯 / 地排灯 / Cyc | 照天幕的条形/方形泛光 | ledBar（条形）或 wash |
| 频闪 / 频闪灯 / Strobe / Atomic / JDC | 频闪 | strobe |
| 观众灯 / 四眼灯 / 二眼灯 / Blinder / 致盲 | 照观众的大功率泛光 | strobe |
| 洗墙灯 / 灯条 / 线条灯 / 条灯 / Bar / Batten / Pixel Bar | 条形 LED | ledBar |
| 矩阵灯 / Matrix / MagicPanel | 像素矩阵面板 | wash（或拆成多个小 beam） |
| 追光灯 / 追光 / Followspot | 人工跟踪的远距离聚光 | beam（3–8°） |
| 激光灯 / Laser | 激光，不属于灯具 | 不建议自动识别为灯 |

### 3ds Max 组名可能出现的英文关键词（按优先级匹配）

- **strobe**：`strobe`, `atomic`, `jdc`, `color strike`, `strike`, `blinder`, `pixel line`, `频闪`, `观众灯`, `四眼`, `致盲`
- **ledBar**：`bar`, `batten`, `x4 bar`, `pxl bar`, `sixbar`, `dotline`, `wall wash`, `灯条`, `洗墙`, `线条`, `地排`, `天排`
- **beam**：`beam`, `sharpy`, `megapointe`, `pointe`, `mythos`, `xtylos`, `cobra`, `bolt`, `bootes`, `geist`, `7r`, `230`, `380`, `bsw`, `hybrid`, `proteus hybrid`, `followspot`, `cyrano`, `光束`, `三合一`, `追光`
- **wash**：`wash`, `aura`, `quantum`, `spiider`, `b-eye`, `beye`, `x5`, `x4`, `rogue`, `rayzor`, `neozone`, `par`, `colorsource`, `magicpanel`, `染色`, `帕`, `蜂眼`, `柔光`；切割/图案类 `profile`, `spot`, `bmfl`, `forte`, `esprite`, `viper`, `mac ultra`, `khamsin`, `diablo`, `perseo`, `scenius`, `maximus`, `source four`, `s4`, `sana`, `切割`, `图案`, `成像`, `面光`

匹配建议：先匹配 strobe 和 ledBar。`X4 Bar` 必须先于 `X4` 判断；`Proteus Hybrid` 和 `Proteus Maximus` 都含 `proteus`，要先匹配完整型号。`PAR` 会误中 `parent`、`part` 之类的英文词，最好按词边界匹配。`230`、`380` 这类纯数字只在同时出现“光束”或 `beam` 时才使用。

## 5. 推荐默认值

| 渲染类型 | 现在 | 推荐 | 依据 |
|---|---|---|---|
| beam | 3°，镜头半径 10 cm | **3°，镜头半径 7.5 cm**（直径 150 mm） | 光束灯固定角/光束模式最小角：Sharpy 3.8°、Mythos 2 2.5°、Pointe 2.5°、MegaPointe 1.8°、BOOTES 2°、GEIST 3°、Xtylos 1°，所以 3° 合理（可用 2–4°）。前镜：Pointe 110、LIBRA 120、Sharpy Plus 135、MegaPointe 150、Xtylos 150、Mythos 2 160、BOOTES 160、LEO 165、Cobra² 170、GEIST 230，中位数约 150–160 mm。原来的 20 cm 直径偏大。 |
| wash | 18°，镜头半径 15 cm | **20°，镜头半径 13 cm** | LED 染色灯变焦范围约 4–60°（Aura XB 10–60、Quantum 11–59、R2X 7.3–64、B-EYE K20 4–60、X5 3.5–63），演出中常用中段约 15–30°，取 20°。前镜只有 GLP X5 公布了 260 mm；ETC ColorSource PAR 出光口 190 mm，PAR64 灯泡 204 mm。所以染色灯取 26 cm 直径。若属于帕灯，建议半径 10 cm、角度 25°。切割/图案灯若归到 wash，建议半径 8 cm（前镜 119–180 mm，中位约 150–160 mm）、角度 20–25°。 |
| strobe | 40×20 cm 面板 | **36×12 cm 面板，角度约 90°** | GLP JDC1 机身正面 390×150 mm，光束角 86°；JDC2 每块透镜 377×111 mm，光束角 110×35°；Color STRIKE M 灯条光束角 95×50°；ACME PIXEL LINE 102–108°。所以“长条形频闪面”比 40×20 cm 更接近主流。Atomic 3000 LED 和 STRIKE 4 观众灯官方未公布发光面，按机身判断大致是 40×20 cm 左右的方形面板，可作为 blinder 的备用尺寸。90° 光锥在画面里会很大，渲染时建议降低光锥不透明度或缩短长度。 |
| ledBar | 100×5 cm | **100×8 cm，角度 25°** | 1 m 灯条最常见：X4 Bar 20 为 1000×100 mm，PXL Bar 16 为 1000×139 mm，DOTLINE360 为 1000 mm 长；0.5 m 版本有 X4 Bar 10 和 PIXEL LINE 500。厂商只公布机身宽度（100–140 mm），没有发光条宽度，透镜区按机身宽约八成估算为 8 cm，这一点没有官方数据。角度：变焦灯条 3.5–50°（X4 Bar 7–50、PXL Bar 5.8–47.9），固定款 SixBar 30°，取 25°。 |

## 6. 无法核实 / 留空项

- **前镜直径未公布**：Sharpy（搜索摘要称 185 mm，未能打开原文，未采用）、Spiider、B-EYE K20、MAC Aura XB、MAC Quantum Wash、GLP X4 L、Rogue R2X、Rayzor 760、Proteus Hybrid、ETC Source Four、Cyrano 追光、NEOZONE。
- **发光面尺寸未公布**：Atomic 3000 LED、JDC1（只有机身）、Color STRIKE M、STRIKE 4、SixBar、PXL Bar 16、MagicPanel 整面。表中写的都是机身外形，备注已说明。
- **Atomic 3000 LED**：光束角官方未公布。
- **国产型号**：浩洋 TERBLY、雅江 SilverStar、明道 GTD、彩熠 FINE ART 的具体型号参数，官网拦截自动访问，无法取得。因此国产型号只收录了 ACME。各厂商的春晚使用记录，除 ACME 的官方案例外，都来自厂商自述。
- **其他来源问题**：Martin、Elation（部分）、Clay Paky Mythos 2 的数据来自托管在经销商网站上的官方规格书，原厂网站拒绝自动访问。
