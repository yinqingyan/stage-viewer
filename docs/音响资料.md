# 音响（线阵/超低）参考资料

用途：舞美 3ds Max 模型一般不含音响，3D 预览工具需要自己在舞台两侧画出吊挂线阵（主扩、侧扩）、超低（吊挂或地堆）和台口前补。本文给出真实型号的外形尺寸、重量、单元间夹角等数据，以及真实演出的吊挂配置，供工具做预设和默认值。机器可读版本见同目录 `speakers-reference.json`（一个数组，字段与下表一致，另含 `keywords[]`）。

整理时间：2026-11。共 60 款：国际品牌 50 款，国产 10 款（国产官网经东京服务器访问）。所有数字来自表中链接的页面或官方 PDF（已实际打开核对），没有公开的数据留空，不做猜测。

## 1. 数据说明

- **尺寸**：W×H×D（宽×高×深，mm）。线阵箱体是“横放的扁箱”：宽是左右方向（1–1.4 m），高是单只的垂直厚度（0.25–0.45 m），深是前后方向。Adamson 箱体为梯形，高度取前高，后高见备注。部分尺寸不含吊挂插销或轮板，见备注。
- **水平覆盖**：厂商标称水平指向角。可调的（L-Acoustics Panflex/L-Fins、PANTHER L/M/W 版本、NEXO 法兰）取表中值，其余档位见备注。
- **垂直覆盖**：多数厂商不公布单只的垂直覆盖（说“取决于阵列”），留空。L-Acoustics 取产品页上的“V”值。
- **夹角（splay）**：相邻两只箱体之间的夹角范围和可选档位。档位是吊挂件上的固定孔位，只能取列表里的值，不是连续可调。超低吊挂通常只有 0° 或 2°/2.5°。
- **最大数量**：吊架（bumper/飞框）按厂商吊挂手册允许的最多箱数。L-Acoustics 手册分“安全上限/最大上限”，表中填最大值，安全值在备注；实际能挂多少还要经厂商软件（Soundvision、ArrayCalc、MAPP 等）核算。
- **吊架**：飞框的尺寸/重量。大部分厂商只在图纸或 CAD 里给吊架尺寸，文本不可提取，所以多数只有重量。L-Acoustics K2/K3 吊架尺寸的“宽/高/深”是按手册图示推定的。
- **sourceType**：`manufacturer` 为厂商官网页面或官网 PDF；`dealer` 为经销商/区域运营站（本表仅锐丰 3 款的尺寸重量来自锐丰山东运营中心 m.sd-lax.com，官网规格页不可用）。
- 特别标注：Adamson E15/E12 的夹角档位来自第三方网站上的官方用户手册镜像（Adamson 下载站返回 520 无法访问），使用前宜核对；声扬 VCX 的水平 80° 来自展会展商页（官网页把 H/V 写反）；锐丰 OP3122 官方写“90°×30°”，30° 对线阵单元偏大，原样保留；音王 G210SA 官网没写尺寸顺序；声扬 SS2 官网两处重量矛盾（90/78 kg，取 90）。

## 4. 术语

| 术语 | 含义 | 在 3D 里怎么画 |
|---|---|---|
| 线阵（线阵列音箱，line array） | 多只相同的扁平箱体上下串接，单只之间带小夹角，整体成 J 形弧线 | 一列 N 只箱体，逐只累加夹角 |
| 主扩（main PA / mains） | 舞台左右两侧最主要的扩声系统，通常是吊挂线阵 | 台口左右各一列，最长、最大 |
| 侧扩 / 外补（side hang / out-fill） | 主扩外侧再挂的一列，覆盖侧面看台（体育馆/体育场常见） | 主扩外侧 3–6 m，水平向外转 30–60°，通常比主扩短 |
| 补声（fill） | 主扩覆盖不到区域的补充音箱的总称（前补、侧补、下补、延时等） | 小箱体或短阵列 |
| 前补（front fill） | 放在舞台台唇/台口前沿的小音箱，覆盖前几排观众 | 台唇上每隔 4–6 m 一只紧凑箱，朝向观众 |
| 延时（delay） | 场地中后部的补声塔或吊挂，信号做延时对齐 | 观众区中后部塔架上的短阵列 |
| 超低（subwoofer，sub） | 低频音箱，体积大、重 | 地堆在台前/台侧，或在主扩旁/后吊挂一列 |
| 吊挂（flown / 吊装） | 用电动葫芦把阵列吊在桁架或屋顶吊点上 | 吊架 + 箱体列，悬空 |
| 地堆（ground stack） | 直接码放在地面或台口前 | 箱体叠放在地面，通常 1–3 层 |
| 点声源（point source） | 单只就能工作的普通音箱（非线阵），如返送、补声小箱 | 单个盒子 |
| 吊架 / 飞框（bumper / flying frame / array frame / grid） | 线阵最上方的金属框，挂葫芦链条，下面连接箱体 | 箱体顶部一条与箱同宽的扁框 |
| 夹角（splay angle） | 相邻两只箱体之间的倾角差 | 第 i 只的俯角 = 吊架俯角 + 前 i 个夹角之和 |

## 5. 未选型号时的通用线阵画法（建议默认值）

依据：第 2 节中 27 款大型线阵单元的尺寸中位数为 宽 1086 / 高 367 / 深 544 mm、重 60 kg、水平 90°；14 款紧凑线阵中位数 719 / 281 / 500 mm、28 kg、水平 105°；18 款超低中位数 1160 / 556 / 739 mm、87 kg。默认值取中位数附近的整数，画出来和 K2、A12、PANTHER、AT3212-V2、VCL 这一类主流箱体在视觉上一致。

**主扩箱体（默认）**：1100 × 370 × 550 mm（W×H×D），60 kg，水平覆盖 90°。
**吊架**：宽同箱体（约 1150 mm），高约 120 mm，深约 550 mm。厂商吊架尺寸大多只有图纸，这是按 K2-BUMP 图示（约 1387 × 115 × 520 mm）比例推的画图值，不是某型号的实测数据。
**每侧数量**：
- 默认 12 只（多数大型演唱会、体育馆巡演主扩在 12–16 只之间，见第 3 节第 6、7、10 行）。
- 演播厅/剧院类晚会：6 只（央视一号演播厅为每侧 5 × K2）。
- 体育场/户外大型晚会：16 只（The Killers、PSY、Evanescence 都在 16 只左右）。
- 按厂商吊挂上限，单列不要超过 24 只。
**夹角（J 形）**：上部打远处用小角度，下部打近处逐渐加大。12 只的默认值：吊架俯角 −2°（向下），单元间夹角 [0.5, 0.5, 1, 1, 1.5, 2, 2.5, 3, 4, 5, 6]（共 27°，最下面一只约朝下 29°）。可按比例截断/拉伸到 N 只：前 1/3 取 0.5–1°，中段 1.5–3°，最后几只 4–6°。这些值都在主流型号的档位范围内（如 K2 0.25–10°、A12 0.25–10°、GSL 0–7°）。
**吊挂高度**：
- 吊架顶部离地 = min(场地吊点/桁架高度 − 0.5 m, 演播厅 10 m / 体育馆 14 m / 户外体育场 18 m)。
- 保证阵列最下面一只底部离地 ≥ 5 m，并且不低于舞台 LED 屏底边。12 只箱体总高约 12 × 0.37 + 0.12 ≈ 4.6 m，再加 J 形弯曲后高度略小。
- 这是画图用的经验规则，不来自某个厂商文档。实际高度由声学设计软件决定，主要看最远观众区的视线和舞台视觉遮挡。
**位置**：台口（或主 LED 屏）左右边缘外侧 1–2 m，箱体前沿与台口线大致对齐或略向前；水平方向向场地中线内转 0–10°。
**侧扩**：主扩外侧 4–6 m，每侧约为主扩数量的 2/3（如 8 只），水平向外转 45°。
**超低**：
- 默认箱体 1150 × 560 × 750 mm，87 kg。
- 地堆：台前一排每侧 3–4 组、每组 2 层；或在主扩正下方堆 2–3 层。
- 体育馆以上规模可在主扩后方（或旁边）再吊一列 6–10 只超低，夹角全 0°（超低吊挂只允许 0°或 2°/2.5°，见表）。
**前补**：紧凑箱 720 × 280 × 500 mm（28 kg），放在台唇上，每隔 4–6 m 一只，略朝上。
**模型细节**：
- 每只箱体正面画深灰网罩，侧面、背面为黑色。
- 箱体前后各有吊挂连接件，夹角改变时绕前沿上缘转动。线阵单元都是前沿相接、后沿张开，所以计算时以前缘铰点作为旋转中心。
