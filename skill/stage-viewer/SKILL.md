# 舞美三维查看器

把一个 3D 舞美模型变成**一个 .html 文件**：three.js、查看器、模型、贴图全部内嵌，不联网、不装软件，双击就能在电脑或手机浏览器打开，发微信、邮件即可分享。

只需要 Python 3 标准库，不需要 Blender、Node 或网络。

## 文件

- `scripts/build_html.py`：检查模型、生成 html
- `scripts/fbx_strip.py`：模型太大（带大量灯具、桌椅）时先用它精简
- `assets/viewer-template.html`：预先打包好的查看器模板，**不要修改**
- `examples/stage.config.json`：一份完整配置（升降屏、灯光、桌椅），其中灯具和桌椅的条目可以直接复用，见「灯光与桌椅」

## 流程

### 0. 拿到模型文件

- 用户传来 `.zip` 时，用 Python 的 `zipfile` 解压出里面的 `.fbx`。**RAR 打不开**，请用户改成 zip 再传。
- 只支持 `.fbx` 和 `.glb`。其他格式（.max、.obj、.c4d、.skp 等）请用户先导出为 FBX。

### 1. 检查模型

```bash
python3 scripts/build_html.py 模型.fbx --inspect
```

输出 FBX 版本、单位、构件数量、每张贴图是否嵌入，以及全部构件名。

- 有贴图显示「未嵌入」：告诉用户在 3ds Max 里 **文件 → 导出 → FBX，勾选「嵌入的媒体 (Embed Media)」** 重新导出，否则网页里屏幕内容不会显示（白模照常可看）。不要因此停下，可以先生成白模版。

### 2. 模型超过约 100MB：先精简

带几百台灯具、几百把椅子的模型可能有上 GB，浏览器打不开。灯具和桌椅的模型细节大部分是螺丝、散热片，网页里由查看器画成简单形状，所以可以去掉它们的几何体，只留位置和朝向：

```bash
python3 scripts/fbx_strip.py 模型.fbx 模型-精简.fbx
```

它会列出识别到的灯具/家具型号。默认识别 3d66 模型库的组名（`Group-数字-数字-…`、`3d66Group…`）；别的命名用 `--fixture '正则'` 指定。按块读取，1GB 以上也只占很少内存。

不知道灯具叫什么名字时，先自动分析：

```bash
python3 scripts/fbx_strip.py 模型.fbx --detect 型号.json
```

它不看名字，找出结构相同、重复出现 4 次以上的组，每种一行：数量、部件数、常见名字、在哪些组里。「包含 Kx」的是一整排灯架、一套桌椅这样的整体，「在 Kx 里面」的是整体里的一员。`scripts/library.json` 里的已知型号会自动填好用途（`[beam]`、`[chair]` 等），没认出来的显示 `[?]`。请用户确认：在 `型号.json` 里给 `[?]` 的型号填 `role`（灯：beam / wash / strobe / bar；桌椅：chair / stool / table），不是灯具桌椅的留空。然后一步精简并生成配置：

```bash
python3 scripts/fbx_strip.py 模型.fbx 模型-精简.fbx --kinds 型号.json --config 配置.json
```

配置里的 `fixtures`、`props` 会被替换，其余字段保留。已知型号用库里的精确参数；新型号暂时按默认大小显示，会提示出来。

精简后**必须配合配置文件**里的 `fixtures`（灯）和 `props`（桌椅），否则这些东西在网页里会消失。见下文「灯光与桌椅」。

### 3. 生成 html

```bash
python3 scripts/build_html.py 模型.fbx --title "晚会名称" -c 配置.json -o 输出.html
```

不需要升降屏、灯光时可以不加 `-c`。把生成的 html 文件交给用户下载。

### 4. 告诉用户怎么用

- **浏览**：拖动旋转、滚轮缩放、右键平移（手机：单指旋转、双指缩放）；底部有正立面、左侧 45°、右侧 45°、平面 4 个视角，「人物走动」「导摄模式」两个入口，「显示」菜单里切白模+线、屏幕内容、人物比例、网格（默认材质显示，按 Max 里的 V-Ray 参数还原颜色、发光、金属反光）；点击构件显示名称和尺寸
- **鸟瞰飞行**（电脑）：普通浏览时 WASD 前后左右、E/Q 升降、Shift 加速，镜头和旋转中心一起移动
- **机位**（导摄模式的右侧面板；普通浏览只显示升降屏和灯光）：添加机位（长焦座机 / 座机 / 摇臂 / 轨道 / 游机）后点地面放置；可选镜头型号（Canon、Fujinon 常用 2/3 英寸转播镜头）、高度（滑块或预设：三脚架 1.5m～大摇臂 9m）和变焦；场景里画出取景框，左下小窗显示 16:9 机位画面、安全框、焦距和景别，对准点上有 1.75m 人形参照。机位存在浏览器里，「复制机位」得到的 JSON 放进配置 `cameras` 后重新生成，别人打开也能看到
- **导摄模式**（底部「导摄模式」按钮，或网址后加 `#dp` 直接进入）：舞美顶视图，拖动平移、滚轮缩放；剖切滑块隐藏头顶桁架和灯具。面板里选类型、填编号后点平面图放机位；拖机位标签 = 移，拖对准点 = 摇；「测距」按住拖线，从机位标签开始拖显示水平距离和镜头到人胸口的斜距。左上角机位窗口里拖动 = 摇/俯仰，滚轮 = 推拉，双击放大
- **轨道**：类型选「轨道」的机位带一根地面轨道（默认 6m，平行舞台）。面板里调长度、角度（0° 平行舞台，有「平行舞台」「垂直舞台」快捷按钮）、摄像机在轨道上的位置、速度；导摄顶视图里也可以拖白色端点改轨道方向，拖机位标签整根移动。「▶ 预演」让摄像机沿轨道运动（可往返），默认横移、朝向不变，打开「边移边摇」则一直对准对准点，机位窗口实时显示画面
- **焦点位**：机位面板「◎ 焦点位」后在舞台上点一下，所有机位同时对准那里（人胸口 1.5m 高），画面上画出每台机位到焦点的连线和斜距，面板列出斜距、水平距离、焦距和景别。定了焦点之后所有机位跟焦：移机位、轨道预演、新放的机位都始终对准焦点（摇/俯仰滑块锁住），距离实时更新；「清除焦点」后恢复手动摇
- **人物走动**：第一人称，身高 1.75m。电脑 WASD 移动、拖动转向、Shift 加速、空格跳、C 坐下/站起、Esc 退出；手机左下摇杆移动、拖动转向、右下「跳」「坐下」按钮。能走上 0.6m 以内的台阶，会被墙挡住
- **坐下**：坐到 4m 内最近的座位（长凳、椅子、圆凳），面朝舞台，眼高 1.2m
- **屏幕内容**：带贴图的面当作 LED 屏自发光显示，可开关
- **观众视角**：底部「观众视角」切到平面图，点一个座位就坐过去看（坐姿眼高、面朝屏幕），显示离屏幕的距离；「最左」「最右」「最后一排」一键坐到最偏、最远的位置；没认出座位时点地面以坐姿高度看
- **截图**：底部相机图标，把当前画面存成 2 倍清晰度的 PNG，不带界面
- **环绕视频**：相机图标旁的摄像机图标，选角度（90° / 180° / 360°）、时长（10 / 20 / 30 秒）、方向，从当前视角绕旋转中心转一圈录成视频（Chrome、Edge、Safari；能存 mp4 就存 mp4，否则 webm），录制时界面收起
- **表面材质**：点地面、台面等构件，在信息卡里换成地毯、水泥、木地板、地胶、亮面，可选颜色；同材质名的构件一起换。改过后右侧出现「保存为新文件」，下载一个带着这些改动的新 html，发给别人打开就是这个样子
- **右侧面板**（有配置时出现，可折叠）：升降屏滑块；灯光每组一个开关、全开全关、亮度、星光，部分组有「光束」开关。有灯开着时环境会自动变暗

## 秀导走位版（可选）

同一个模型加 `--show` 生成给秀导用的版本（不带机位、导摄，只有顶视图和音乐分轨时间轴）：

```bash
python3 scripts/build_html.py 模型.fbx --title "晚会名称" -c 配置.json --show -o 秀导走位.html
```

秀导版也可以**不带模型**（约 1 MB），由秀导在网页里导入舞美平面图：

```bash
python3 scripts/build_html.py --show --title "晚会名称" -o 秀导走位.html
```

- 舞美图：右侧「舞美图」导入 jpg/png 平面图（图的上方是舞台、下方是观众席，⟳ 90° 可转），填「图片实际宽度」米数定比例（人的圆点约 0.9 米、走速都按它算）。导入后不再显示三维模型，「去掉」恢复；平面图随「保存」写进 .json
- 导入音乐（mp3/wav），时间码 分:秒:帧（25 帧），只和音乐对齐
- 「＋ 单人」放演员，「＋ 一组」放舞团（同色方阵）；每个人可改名字、颜色（40 种预设 + 自定义），整组选中时改组名、组颜色
- 分轨：每组、每个演员一条轨道，每段移动是轨道上的一段素材（几分几秒到几分几秒、从哪到哪）。拖素材中间平移，拖两头改出发/到位时间；组轨道上的一段带着全组一起改，点 ▸ 展开后可单独拖某个组员（他仍属于这个组）
- 画移动：时间轴走到出发时间，在平面图上拖人，拖过的线就是路线，松手处是到位位置；00:00:00 时拖人是改开场站位。超过 3 m/s 标红
- 改路线：选中一段移动后，路线上的白色拐点（带号）和黄色到位点可以拖；双击拐点删掉，双击路线加拐点
- 旋转队形：选中两人以上，队形外侧的黄色旋转手柄拖动旋转（Shift 每 15° 一档）。选中了某段移动时转的是它的到位队形，否则从当前时间出发沿圆弧转过去
- 平面图操作：左键只用来选人、拖人画路线、拖空白处框选（Shift 加选），不会移动图；右键或中键拖动移动图；鼠标滚轮缩放，触控板双指滑动移动图、双指捏合缩放
- 「从这里下场」「上场…」；Ctrl/⌘+Z 撤销，空格播放；「＋ 标记」在音乐上打点（前奏、副歌…）
- 「保存」得到一个 .json（音乐也在里面），在同一个 html 里「打开」继续编辑或查看；「导出截图」得到开场和每个标记的顶视图（zip）

## 配置

写一个 JSON，用 `-c` 传入。每一项都可选：

| 字段 | 说明 |
|---|---|
| `title` | 项目名称（页面标题），默认「舞美三维查看」。也可用命令行 `--title`。打开 html 后点右上角的名字可以改名，新名字存在本机浏览器里；秀导版保存的走位文件也带着名字，打开时一并恢复 |
| `audience` | 观众席在模型哪一侧：`+z`（默认）、`-z`、`+x`、`-x`。如果「观众席」机位看到的是舞台背面，就换一个方向重新生成。用户也可以在网址后加 `?audience=-z` 先试 |
| `lifts` | 升降屏，**用户提出才加**，见「升降屏」 |
| `fixtures` | 灯具，见「灯光与桌椅」 |
| `props` | 桌椅凳替身，见「灯光与桌椅」 |
| `aim` | 统一光束方向：`{ "floorBelow": 3 }` 表示灯口离地 3 米以下的朝正上方，其余朝观众席水平打出 |
| `lightGroups` | 按灯光组名单独设置，`"*"` 对所有组生效：`glowOnly` 只亮灯不出光束；`beamSwitch` 给这组一个「光束」开关（默认关） |
| `materialOverrides` | 材质模式下改颜色，按构件名 `mesh` 或材质名 `material`（正则）匹配：`{ "mesh": "^Truss", "color": "#d9d9d4" }`；舞台亮面：`{ "material": "^StageFloor$", "color": "#3a3a42", "glow": "#1c1c22", "reflect": 0.5 }`（glow 让它在暗场里也和地面分得开，reflect 是反光强度） |
| `labels` | 在构件顶面写字：`{ "mesh": "^Area_VIP$", "text": "贵宾区", "color": "#d8d8d8" }` |
| `textures` | 替换构件贴图（如客户 logo）：`{ "mesh": "^Logo_", "image": "logo.png" }`，图片路径相对配置文件，打包时会嵌进 html，图片铺满构件每个面、自发光显示 |
| `props[].color` | 桌椅替身在材质模式下的颜色 |
| `surfaces` | 表面材质，一般在网页里选好后「保存为新文件」自动写入：`{ "material": "台面", "type": "wood", "color": "#3b3029" }`，按材质名 `material` 或构件名 `mesh` 完全匹配（不是正则）；`type` 可选 `carpet` 地毯、`concrete` 水泥、`wood` 木地板、`vinyl` 地胶、`gloss` 亮面。纹理按真实尺寸铺贴，不需要模型展 UV |
| `seats` | 座位识别规则（高度、长边范围），一般不用改 |

### 升降屏

每块屏一项，`name` 是 3ds Max 里的对象名（`--inspect` 列出的构件名；也可以让用户在生成的 html 里点一下那块屏，左上角会显示名字）。高度都指**屏幕底边离正下方台面的距离**，起始高度就是模型里的位置：

- 只写 `name`、`label`：屏在高处，只能往下降，最低落到台面
- `"rise": 8.5`：屏在低处，最多再升 8.5 米
- `"top": 5.3`：底边最高升到离台面 5.3 米

向用户确认时要问清三件事：哪块屏（对象名）、现在在顶还是在底、能升/降到多少米。用户说的尺寸若是页面右上角的「尺寸 a × b × c m」，那是整个场景的尺寸，不是某块屏的。

### 灯光与桌椅

灯光面板按模型里**最外层的组**分组，组名就是开关上的名字，所以请用户在 Max 里把每组灯打成一个组并起好名字。

`examples/stage.config.json` 里已经配好下列 3d66 模型库的型号，模型里用的是同样的模型时，把对应条目原样复制到新配置即可：

| 组名前缀 | 是什么 | 画法 |
|---|---|---|
| `Group-1514655-27-` | 摇头光束灯 | 圆形灯口 + 3° 窄光束 |
| `Group-1514655-1-` | LED 染色摇头灯 | 大圆灯口 + 18° 柔光 |
| `Group-1514655-31-` | 频闪 | 发光长方形面板 |
| `Group-1514655-36-` | LED 灯条 | 发光条 |
| `3d66Group`（4 个部件） | 椅子 | 座面 + 靠背，可坐 |
| `3d66Group`（2 个部件） | 圆凳 | 圆柱，可坐 |
| `Group-13929769-2-` | 圆桌（带桌布） | 圆台 |

`fbx_strip.py` 列出的型号里**有上表没有的**，说明用了新的灯具或家具模型，它的灯口位置、朝向需要分析模型才能配置。这时告诉用户：这些东西在网页里暂时不会显示，需要维护这个工具的人补充该型号的配置；其余部分照常生成。不要自己猜 `lens`、`dir` 的数值。

## 常见问题

- **屏幕是白的**：贴图没嵌入，见第 1 步。
- **模型大小明显不对（人物比例像蚂蚁或巨人）**：FBX 单位异常。看 `--inspect` 的单位行，请用户在 3ds Max 导出时把单位设为厘米或米后重新导出。
- **html 很大**：大小约等于 FBX 大小。超过 100MB 先用 `fbx_strip.py`；贴图大时请用户导出前把贴图缩小到 2048 像素以内。
- **浏览器要求**：Chrome / Edge / Firefox 近两年版本，Safari 16.4+（iOS 16.4+）。
- 不要修改 `assets/viewer-template.html`，也不要手工拼接 html，一律用 `build_html.py` 生成。
