# 舞美三维查看器：安装说明

这个文件夹是一个 AI skill：把舞美 3D 模型（FBX）变成一个能双击打开的 html，可以三维浏览、第一人称走动、坐到观众席看舞台。

## 在 ChatGPT 里使用

**方式一：ChatGPT 有「技能 / Skills」功能**
上传 `stage-viewer-skill.zip`。之后上传模型并说「做成舞美查看 html」就行。

**方式二：用「项目 (Project)」**
1. 新建一个项目，比如「舞美查看」
2. 把 `stage-viewer-skill.zip` 上传到项目文件
3. 在项目说明 / 自定义指令里写：
   > 我上传舞美 3D 模型时，先解压项目文件里的 stage-viewer-skill.zip，严格按照其中 stage-viewer/SKILL.md 的步骤，用 scripts/build_html.py 生成 html 给我下载。
4. 以后在这个项目里上传 FBX 即可

## 不用 AI，直接自己生成

电脑装有 Python 3（Mac 自带）就可以：

```bash
python3 stage-viewer/scripts/build_html.py 你的模型.fbx --title "晚会名称"
```

## 模型很大（带灯具、桌椅）怎么传

- ChatGPT 单个文件上限约 512MB。大的 FBX 先压成 **zip**（不要用 RAR，ChatGPT 打不开），FBX 压缩率很高，1.4GB 一般能压到几十 MB
- skill 会先把灯具、桌椅精简掉，网页里由查看器画成灯口、光束和简单桌椅
- 用的灯具、桌椅如果不是示例里那几种 3d66 模型，需要先补配置，ChatGPT 会提示

## 3ds Max 导出注意

- 文件 → 导出 → FBX，**勾选「嵌入的媒体 (Embed Media)」**，屏幕贴图才会显示
- 每组灯打成一个组并起名（如「顶部光束」「舞台两侧」），组名就是网页上的灯光开关
- 屏幕材质用标准材质或物理材质，贴图放在漫反射 / 基础颜色通道；V-Ray、Corona 材质的贴图会丢
